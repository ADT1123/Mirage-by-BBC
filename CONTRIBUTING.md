# Contributing

Thanks for helping make Mirage better.

1. **Fork** this repo and create a branch: `git checkout -b my-change`.
2. Run it: `npm install`, then `npm start`.
3. Keep changes focused: one fix or feature per pull request.
4. Check your change works on your OS (Windows or Linux), then open a **pull request** to `main`.

All changes go through pull requests. Nobody pushes to `main` directly; every PR is reviewed
before it's merged, and an automatic check must pass first.

## Style

- Plain JavaScript, no build step. Match the code around your change.
- Short comments that explain *why*, not *what*.
- No new dependencies unless there's no reasonable way around it.

## Reporting bugs

Open an issue with what you did, what you expected, what happened, and your OS.
For security problems, see [SECURITY.md](SECURITY.md) instead.
